# Zenn Contents Repository Rules

記事は `articles/`、本は `books/`、画像は `images/` に置きます。以下のCLIコマンドはリポジトリのルートで実行します。
エージェントは以下のルールに従ってアシストを行ってください。

## 1. 記事・本の作成方法
- 新規記事を作成する際は、必ず `npx zenn new:article` コマンドを実行してファイルを生成してください。
- 新規本を作成する際は、必ず `npx zenn new:book` コマンドを実行してディレクトリとファイルを生成してください。

## 2. 記事の構成と見出し

構成、図のデザイン、補足、参考資料の書き方は [CDKで構築するレイクハウスCI/CDの記事](https://zenn.dev/kkoch5t2/articles/aws-cdk-lakehouse-cicd) を見本にしてください。

- 冒頭で「何を説明するか」または「何を検証するか」を示します。検証記事は目的、全体構成、手順、結果、まとめを基本の順序とし、解説記事は概要から仕組みや具体例へ進めます。記事の内容に合わせて節を調整してください。
- 大見出し（`##`）は先頭に内容を表す絵文字を1つ付けます。`## 参考資料` と小見出し（`###` 以降）は文字だけにします。
- 見出しは短く、扱う内容が伝わる言葉にします（例：`## 🏗️ 全体構成`、`### アカウントの役割`）。小見出しは親見出しの内容を掘り下げるときに使います。

## 3. 図と検証キャプチャ

- **検証記事**には、手順の前に全体構成図を入れます。工程やデータの流れ、成功・失敗の分岐で説明が必要な箇所には、節に合った図を添えます。主要工程の設定・実行・結果は、該当する手順や説明の近くに実画面のキャプチャを入れ、どの項目や結果を見ればよいかを本文またはキャプションで示します。画面の取得ができなかった結果は、実際に保存した出力やログを掲載します。
- **解説記事**には、冒頭付近の全体像に加え、主要な概念、処理の流れ、違いを説明する節にも図を入れます。一つの図は一つの説明に絞り、対応する本文の近くに置きます。
- **図のデザイン**は、見本記事の全体構成図とパイプラインの進行図に合わせます。明るい背景に、アカウント・環境・役割などのまとまりを枠で示します。同じサービスや役割は図をまたいでアイコンと色をそろえ、処理の向きは矢印で示します。本文で順番を追うときは図と本文で番号を対応させ、AWSサービスを描くときは公式アイコンを使います。
- 図とキャプチャには内容が分かる代替テキストを付けます。キャプチャに含まれる個人情報や識別子は公開に必要な範囲を確認し、不要なものをマスクしてください。

## 4. Markdownの記法 (Zenn Flavored Markdown)
Zenn独自のMarkdown拡張記法に準拠して記述・修正を行ってください。
- **メッセージ機能**: 補足や注意書きを記述する際は、`:::message` を使用してください。
  ```markdown
  :::message
  ここにメッセージを書きます
  :::
  ```
- **アラート機能**: 警告を記述する場合は `:::message alert` を使用します。
- **関連記事**は、内容に直接関係する既存記事を選び、前後に空行を入れてURLを単独の行に置き、リンクカードとして表示します。
- **参考資料**は、記事末尾に `## 参考資料` を置き、実際に参照した公式ドキュメントなどを資料名付きのMarkdownリンクで箇条書きにします。特定の仕様や数値の根拠は、該当する本文にも資料名付きリンクを置きます。
- **コードブロック**: コードブロックには言語名を指定し、必要に応じてファイル名も記述してください（例: ` ```python:main.py ` ）。

## 5. フロントマター (Frontmatter)の取り扱い
各Markdownファイルの先頭にあるYAMLフロントマター（`title`, `emoji`, `type`, `topics`, `published` など）は、Zennの仕様上必須です。
- 記事の本文を修正する際、ユーザーからの明確な指示がない限りフロントマターの設定は変更しないでください。
- **`topics`（タグ）は最大5つまで**しか設定できません。自動設定・追加時も必ず5つ以下に収めてください。

## 6. プレビューの確認
公開前に `npx zenn preview` を実行し、`http://localhost:8000` で見出しの階層、リンクカード、参考資料のリンク、画像の読み込みを確認します。図とキャプチャはPC幅とスマホ幅で確認し、文字の読みやすさや、ラベル・枠・矢印の重なりを確認してください。
